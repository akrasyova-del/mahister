# Мануал: Налаштування зовнішніх сервісів

Система може працювати без реєстрацій у зовнішніх сервісах (mock-режим),
але для отримання реальних TLE-даних рекомендується налаштувати:

---

## 1. Space-Track.org (основне джерело TLE)

**Для чого:** найповніша база TLE, включаючи мало-публічні об'єкти.

**Кроки:**
1. Перейдіть на https://www.space-track.org/auth/createAccount
2. Заповніть форму реєстрації (безкоштовно, потрібна причина використання)
3. Чекайте підтвердження email
4. Після входу перевірте: https://www.space-track.org/basicspacedata/query/class/gp/NORAD_CAT_ID/25544/format/tle/
5. Додайте у `.env`:
   ```
   SPACETRACK_USER=your_email@example.com
   SPACETRACK_PASS=your_password
   ```

**Обмеження:** 300 запитів/хвилину для автентифікованих акаунтів.

---

## 2. CelesTrak (резервне джерело TLE, без реєстрації)

**Для чого:** безкоштовне джерело TLE для більшості відкритих об'єктів.

**Немає реєстрації.** Система використовує автоматично.

- URL-формат: `https://celestrak.org/satcat/records/?CATALOG_NUMBER={NORAD_ID}&FORMAT=TLE`
- Обмеження: деякі класифіковані об'єкти відсутні

**Важливо:** частина із 55 КА у списку є класифікованими військовими супутниками РФ
і може бути відсутня в CelesTrak. Для них система позначає статус `TLE_MISSING`.
Можна ввести TLE вручну через API: `POST /api/tle/manual`.

---

## 3. Open-Meteo (погода, без реєстрації)

**Для чого:** реальні погодні дані для телескопів.

**Немає реєстрації.** Використовується автоматично.

- URL: `https://api.open-meteo.com/v1/forecast`
- Ліміт: 10 000 запитів/день (безкоштовно)
- Документація: https://open-meteo.com/en/docs

---

## Mock-режим (для тестування без зовнішніх сервісів)

Додайте у `.env`:
```
MOCK_TLE=true
MOCK_WEATHER=true
```

У mock-режимі система генерує:
- Синтетичні TLE для кожного типу орбіти (LEO/MEO/GEO/HEO)
- Случайні але реалістичні погодні дані

---

## Ручне введення TLE

Якщо TLE для конкретного КА недоступний автоматично:

```bash
curl -X POST http://localhost:8000/api/tle/manual \
  -H "Content-Type: application/json" \
  -d '{
    "satellite_id": 1,
    "tle_line1": "1 39177U 13028A   24001.00000000  .00000000  00000-0  00000-0 0  9990",
    "tle_line2": "2 39177  97.4000 000.0000 0001000   0.0000   0.0000 15.20000000000014"
  }'
```

TLE можна знайти на:
- https://celestrak.org (пошук за NORAD ID)
- https://www.n2yo.com (вкладка "TLE data")
- https://heavens-above.com
